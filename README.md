# AlphaGuardian AI

🚀 AlphaGuardian AI is an autonomous AI trading intelligence platform designed for the Bitget AI Hackathon S2.

## Features

- 📊 AI Opportunity Analysis
- 🧠 AI Verification Engine
- 📰 News Intelligence
- 👀 Smart Watchlist
- 📈 Portfolio Health
- ⚠️ Risk & Confidence Scoring
- 📊 Interactive Charts
- 🤖 Explainable AI Reasoning
