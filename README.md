# 🚀 AlphaGuardian AI

> **Discover. Verify. Monitor. Trade Smarter.**

AlphaGuardian AI is an autonomous AI-powered trading intelligence platform built for the **Bitget AI Hackathon S2**.

Unlike traditional AI trading assistants, AlphaGuardian AI doesn't simply generate Buy or Sell suggestions. It combines market intelligence, AI verification, news analysis, sentiment evaluation, and explainable reasoning to help traders make more informed decisions when trading Tokenized US Stocks.

# ⚙ How It Works

AlphaGuardian AI follows a multi-stage AI workflow before presenting any opportunity to the user.

## 1️⃣ Market Intelligence

The platform analyzes Tokenized US Stocks using:

- Price
- Volume
- Momentum
- Liquidity
- Market Trend

These signals create a real-time overview of market conditions.

---

## 2️⃣ News Intelligence

Financial news is collected and summarized using AI.

The system identifies:

- Bullish News
- Bearish News
- Important Events
- Market Impact

---

## 3️⃣ AI Verification Engine

Every opportunity passes several AI verification layers.

✔ Trend

✔ Momentum

✔ Volume

✔ Liquidity

✔ News

✔ Sentiment

✔ Risk

Only verified opportunities appear on the dashboard.

---

## 4️⃣ Opportunity Intelligence

For each verified opportunity, AlphaGuardian AI generates:

- AI Confidence Score
- Risk Level
- Potential Upside
- Entry Zone
- Stop Loss
- Take Profit
- AI Summary
- Explainable Reasoning

---

## 5️⃣ Smart Watchlist

Users can monitor selected assets.

The AI automatically generates alerts for:

- Trend Changes
- News Events
- Momentum Shifts
- Risk Increases

---

## 6️⃣ Portfolio Health

The Portfolio Health module analyzes:

- Diversification
- Risk Exposure
- Sector Allocation
- AI Suggestions

---

## 🤖 Explainable AI

Instead of showing only Buy or Sell signals, AlphaGuardian AI explains:

- Why this opportunity exists
- Which signals influenced the decision
- Confidence Score
- Risk Assessment
- Expected Market Behavior

# 🚀 Installation

Clone Repository

```bash
git clone https://github.com/yourusername/AlphaGuardian-AI.git
```

Install Frontend

```bash
npm install
```

Run Frontend

```bash
npm run dev
```

Install Backend

```bash
pip install -r requirements.txt
```

Run Backend

```bash
python app.py
```
